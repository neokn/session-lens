比較

成本是常態請求累加出來的模型估算，不是帳單預測；偶爾的大請求不在常態值裡，實際 context 會長得比圖上快，也只算有跑到觸發點的長 session。閒置壓縮不受這個設定影響，沒有算進來；壓縮損失的上下文也沒有計價。Initial context 越大，累積滿 1M 前能做的請求越少，所以不同 initial context 的總成本不能直接相比，要看同一個 initial context 下誰比較省。Initial context 改變時，假設壓縮後留下的量和要重新寫入 cache 的量也跟著增減同樣多。

這個模型沒有價格資料，無法試算成本。
